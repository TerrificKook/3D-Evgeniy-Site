# Данные, которые нужны до публичного запуска

Все пункты ниже являются внутренними пробелами. Они не должны превращаться в публичные обещания автоматически.

## Бренд и контакты

- [ ] Утверждённое название мастерской.
- [ ] Домен и основной canonical origin.
- [ ] Телефон.
- [ ] Email.
- [ ] Telegram и необходимость WhatsApp.
- [ ] География работы, выдачи и доставки.
- [ ] Юридический статус и реквизиты для сайта.
- [ ] Рабочее время.
- [ ] Реальный срок первичного технического ответа.

## Производственные границы

- [ ] Подтвердить парк оборудования, его состояние и доступность.
- [ ] Материалы, которые стабильно используются на подтверждённых режимах.
- [ ] Максимальные рабочие габариты, которые можно обещать.
- [ ] Публикуемые допуски и метод их проверки, если такие обещания допустимы.
- [ ] Реальная недельная мощность и резерв оборудования.
- [ ] Фактический процент брака и порядок переделки.
- [ ] Полный стоп-лист критичных и неподходящих задач, утверждённый Евгением.
- [ ] Кто выполняет CAD, 3D-сканирование и реверс-инжиниринг.
- [ ] Точность и скорость контура «сканирование → CAD → контроль».
- [ ] Как передаётся и возвращается физический образец.
- [ ] Как проверяется и принимается пилот для каждого направления.
- [ ] Когда пластик отклоняется в пользу металла, ЧПУ, литья или готовой детали.

## Коммерческие правила

- [ ] Минимальный заказ по готовой модели.
- [ ] Минимальная стоимость инженерного этапа.
- [ ] Условия оплаты пилота.
- [ ] Сколько итераций входит в согласованный этап.
- [ ] Правила расчёта и запуска повторной партии.
- [ ] Условия доставки и самовывоза.
- [ ] Гарантия, порядок рекламации и переделки.
- [ ] Допустимый бюджет 30-дневного теста и критерии остановки.

## Кейсы и изображения

- [ ] Разрешение на публикацию первого реального кейса.
- [ ] Фото нестандартной функциональной фурнитуры.
- [ ] Подтверждённая задача клиента и отрасль без раскрытия конфиденциальных данных.
- [ ] Исходные данные.
- [ ] Выполненная инженерная работа.
- [ ] Материал, оборудование, количество, итерации и срок.
- [ ] Способ проверки и приёмки.
- [ ] Подтверждённый результат и наличие повтора.
- [ ] Можно ли называть клиента и публиковать сумму.
- [ ] Реальные фотографии детали по образцу: исходник, измерение, пилот.
- [ ] Реальные фотографии корпуса: компоновка, разъёмы, сборка.
- [ ] Реальные фотографии оснастки: операция, пилот, контроль.
- [ ] Общее фото рабочего процесса без чувствительных данных.

## Форма, данные и право

- [ ] Канал production-отправки заявок.
- [ ] Место и срок хранения заявок.
- [ ] Канал загрузки, максимальный размер и допустимые типы файлов.
- [ ] Правила доступа и удаления файлов.
- [ ] Утверждённая политика обработки персональных данных.
- [ ] Проверенный юристом текст согласия.
- [ ] Реквизиты оператора персональных данных.
- [ ] Тестовая production-заявка прошла полный путь без отправки реальному получателю до разрешения.

## Аналитика и запуск

- [ ] ID Яндекс Метрики.
- [ ] Утверждённый список целей и правила хранения параметров.
- [ ] Проверка аналитики без персональных данных.
- [ ] UTM и источник корректно сохраняются вместе с заявкой после подключения backend.
- [ ] Утверждённый favicon, логотип и карточка для соцсетей.
- [ ] Production origin для canonical и Open Graph.
- [ ] Проверка всех публичных текстов владельцами.
- [ ] Production deployment и реклама разрешены отдельным решением.

# Карта сайта

## Основные маршруты

| Маршрут | Роль | Основное действие |
| --- | --- | --- |
| `/` | Быстро объяснить три типа задач и общий порядок работы | Выбрать задачу или перейти к форме |
| `/detal-po-obraztsu/` | Квалифицировать некритичную деталь по физическому образцу | Прислать данные о детали |
| `/korpusa-dlya-elektroniki/` | Квалифицировать корпус под плату, датчик или прибор | Прислать компоновку и условия |
| `/osnastka-i-konduktory/` | Квалифицировать оснастку под конкретную операцию | Описать операцию, нагрузки и проверку |
| `/cases/` | Показать модель доказательств без выдуманных заказов | Открыть шаблон кейса |
| `/cases/[slug]/` | Показать проверенные поля отдельного кейса | Перейти к форме с типом задачи |
| `/vozmozhnosti-i-ogranicheniya/` | Объяснить границы применимости и стоп-лист | Проверить, подходит ли задача |
| `/quality-and-acceptance/` | Объяснить пилот, контроль, ревизию и приёмку | Описать способ проверки |
| `/contacts/` | Собрать квалифицированную техническую задачу | Сохранить mock-заявку локально |
| `/privacy/` | Показать staging-информацию об обработке данных | Не использовать как утверждённую политику |

## Навигационная логика

- Главная разводит посетителей по трём покупательским ситуациям.
- Каждая продуктовая страница ведёт в единую форму с заранее выбранным типом задачи.
- Страницы ограничений и качества доступны из шапки, футера и продуктовых страниц.
- Кейсы не подменяют доказательства: до появления подтверждённых работ показывается только явно маркированный шаблон.
- Страница малых серий не создаётся до замера мощности; партия описывается как этап после принятого пилота.

## SEO-кластеры

- изготовление пластиковой детали по образцу;
- пластиковые детали на заказ;
- корпус для электроники на заказ;
- прототип корпуса;
- производственный кондуктор;
- оснастка на заказ;
- фиксатор или держатель для производства;
- 3D-сканирование и реверс-инжиниринг как поддерживающие понятия.

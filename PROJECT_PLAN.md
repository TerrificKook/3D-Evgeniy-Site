# План staging-версии

Дата плана: 2026-09-02.

## Цель

Собрать локальную staging-версию сайта как инструмент первичной квалификации B2B-задач. Сайт не обещает цену за грамм, универсальную применимость технологии или неподтверждённые производственные параметры.

## Выбранный подход

- Next.js с App Router и TypeScript в строгом режиме.
- Tailwind CSS и небольшой набор интерфейсных компонентов без тяжёлых декоративных библиотек.
- Статические информационные страницы.
- Централизованный контент в `site/content/` и настройки в `site/config/`.
- Кейсы как типизированные данные; `draftFields` не попадают в публичный вывод.
- Квалификационная форма работает только в mock-режиме и ничего не отправляет наружу.
- Яндекс Метрика включается только при наличии переменной окружения; без ID сайт работает штатно.

## Этапы

1. **Аудит и фиксация рамок** — изучить источники, создать план, карту сайта, список пробелов, журнал решений и статус.
2. **Каркас и дизайн-система** — создать приложение, общую навигацию, футер, токены оформления и мобильный каркас.
3. **Основные страницы** — главная и три продуктовые страницы с единым квалификационным сценарием.
4. **Доказательства и ограничения** — модель кейсов, шаблон демонстрационного проекта, страницы возможностей и контроля качества.
5. **Форма** — сгруппированные поля, сохранение черновика в браузере, валидация, honeypot, UTM/referrer и mock-адаптер.
6. **SEO и аналитика** — metadata, canonical, Open Graph без выдуманного изображения, JSON-LD, sitemap, robots, manifest и безопасная заготовка Метрики.
7. **Проверка и документация** — build, TypeScript, lint, проверка служебных плейсхолдеров, ключевых маршрутов и README.

## Риски запуска

- Нет утверждённых контактов, географии, бренда и SLA.
- Нет подтверждённых материалов, допусков, габаритов, мощности и гарантий.
- Нет кейса с достаточным набором разрешённых для публикации фактов и фотографий.
- Не выбран канал хранения заявок и файлов; mock-форма не является production-приёмником.
- Не утверждены политика обработки данных и текст согласия.
- Не задан ID Яндекс Метрики и не настроены внешние цели.

## Критерии готовности staging

- Работают все маршруты из `SITE_MAP.md`.
- Три продуктовые страницы объясняют задачу, входные данные, пилот и ограничения.
- Кейсы добавляются через данные; черновые поля не публикуются.
- Форма собирает технический минимум, сохраняет черновик и честно работает в mock-режиме.
- Нет выдуманных клиентов, цен, сроков, материалов, допусков и результатов.
- Есть SEO-каркас, sitemap, robots, manifest и отключаемая заготовка Метрики.
- `npm run build`, `npm run typecheck`, `npm run lint` и staging-проверка контента проходят; production-проверка намеренно блокирует запуск до заполнения обязательных параметров.
- README описывает запуск, заполнение, интеграции и checklist публичного запуска.

## Вне текущего этапа

Production deployment, домен, DNS, внешняя отправка формы, рекламные кабинеты, публичные цели Метрики и реальные сообщения клиентам.

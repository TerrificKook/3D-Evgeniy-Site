# Статус проекта

Обновлено: 2026-09-02.

## Текущий этап

Визуальный прототип главной v2 собран и проверен. Для текущего staging настроен статический export и автоматическая публикация приложения из `site/` через GitHub Actions в GitHub Pages.

## Завершено

- Проверена структура исходного комплекта: готового приложения и Git-репозитория нет.
- Прочитаны `AGENTS.md`, `START_SITE_PROMPT.md`, шаблон брифа, шаблон пробелов и материалы `research/`.
- Создан рабочий `PROJECT_BRIEF.md` без выдуманных фактов.
- Созданы `PROJECT_PLAN.md` и `SITE_MAP.md`.
- Создан полный `CONTENT_GAPS.md`.
- Первые архитектурные и контентные решения записаны в `DECISIONS.md`.
- Создано приложение в `site/` с общей навигацией и адаптивной промышленной визуальной системой.
- Готовы главная, три продуктовые страницы, кейсы, ограничения, контроль качества, контакты и staging-информация о данных.
- Добавлена типизированная модель кейсов с непубличными `draftFields`.
- Добавлена трёхшаговая квалификационная форма: локальный черновик, honeypot, клиентская и серверная валидация, UTM/referrer и mock-адаптер без хранения.
- Добавлены metadata, canonical, Open Graph, JSON-LD, sitemap, robots, manifest и favicon.
- Добавлена выключаемая заготовка Яндекс Метрики и каталог событий.
- Добавлены `.env.example`, staging- и production-проверки контента, инструкция заполнения и checklist запуска.
- TypeScript, lint, content-check, build и `npm audit` проходят.
- В браузере проверены 360, 768, 1024 и 1440 px; горизонтального переполнения нет.
- Полный mock-путь формы прошёл локально, POST завершился 200, внешней отправки не было.
- Публичная главная пересобрана как предметный B2B-лендинг: крупный оффер, галерея задач, реальное направление работы, производство, четыре шага и короткая форма.
- Добавлены шесть сгенерированных staging-изображений; все они явно подписаны как визуализации и легко заменяются файлами с теми же именами.
- Главная повторно проверена в браузере на 1440 и 390 px; финальные снимки сохранены в `artifacts/`.
- Настроена статическая сборка GitHub Pages с путём `/3D-Evgeniy-Site`, проверкой HTML и ассетов, а также workflow сборки и публикации.
- GitHub Pages-версия формы проверена без внешней отправки: оба интерфейса сохраняют или валидируют staging-черновик в браузере.

## Не начато

- Подключение реального канала заявок и файлов.
- Подключение ID Яндекс Метрики.
- Заполнение реальных контактов и кейсов.
- Production-запуск формы, домена, аналитики и рекламных кабинетов остаётся вне текущего разрешения.
- Заполнение реальных производственных параметров, контактов, политики и кейсов — требуется от владельцев.

# Чек-лист перед открытием индексации

Текущий статус: **не открывать индексацию**. Staging корректно закрыт правилом `Disallow: /`.

## Обязательные условия

- [ ] Подтверждён production-домен и окончательный адрес сайта.
- [ ] Подтверждено, что мастерская принимает задачи из Москвы и Московской области.
- [ ] Заполнены реальные контакты и разрешён рабочий канал отправки заявок.
- [ ] Удалены или заменены служебные и демонстрационные материалы.
- [ ] Демонстрационный кейс `/cases/functional-detail-demo` исключён из sitemap и индексации либо заменён подтверждённым кейсом.
- [ ] Все изображения и доказательства соответствуют реальным работам или явно обозначены как иллюстрации.
- [ ] Для каждой публичной страницы проверены уникальные Title, description и H1.
- [ ] Canonical указывает на production-домен, а не на GitHub Pages.
- [ ] Sitemap содержит только рабочие production-URL.
- [ ] Выбран единый формат адресов без завершающего слеша; внутренние ссылки, canonical и реклама используют его одинаково.
- [ ] `robots.txt` переведён из staging-режима в production-режим только после выполнения остальных пунктов.
- [ ] Подключена Яндекс Метрика и проверены события квалифицированной заявки без отправки теста реальному получателю.
- [ ] Сайт добавлен в Яндекс Вебмастер и Google Search Console владельцем проекта.
- [ ] Сохранён исходный срез индексации и поисковых показателей.

## Проверка после открытия

- [ ] Главная и целевые страницы возвращают HTTP 200.
- [ ] Варианты с ошибочным слешем не попадают во внутренние ссылки и объявления.
- [ ] Robots и meta robots не запрещают нужные production-страницы.
- [ ] Sitemap доступен и принят поисковыми сервисами.
- [ ] В индексе нет demo-страниц и служебных адресов.
- [ ] Через 7, 14 и 30 дней зафиксированы показы, клики, запросы и квалифицированные обращения.

## Запрет на автоматическое действие

Этот чек-лист не является разрешением менять robots, домен, DNS, Метрику, формы или кабинеты. Для каждого такого шага нужно отдельное подтверждение владельца.

# Исходные наблюдения

- `wordstat/observations.md` — ручной авторизованный срез Яндекс Wordstat.
- `yandex-serp/observations.md` — desktop-срез Яндекс выдачи.
- `aisa/` — payload, оригинальные ответы AIsa и метаданные стоимости. Временный зашифрованный ключ после завершения вызовов удалён.

Секреты, cookies, данные аккаунтов и персональные данные сюда не сохраняются.

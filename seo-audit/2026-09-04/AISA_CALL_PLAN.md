# План использования AIsa

## Ограничения

- Общий предел расходов: 4,50 USD.
- Фактически израсходовано текущим аудитом: 0,064 USD.
- Баланс до пакета: 5,488 USD; после пакета: 5,424 USD.
- Установлен официальный AIsa CLI версии 0.3.0.
- Рекомендуемый рабочий предел вызовов: 4,25 USD; резерв на округление и повтор при технической ошибке: 0,25 USD.
- Ключ не передавался в чат и не хранился в открытом виде. Для выполнения пакета использовалась временная DPAPI-зашифрованная копия, исключённая из Git; после завершения вызовов она удалена.
- Для входа без ключа в истории PowerShell используется `connect-aisa.ps1`.
- До первого вызова проверить доступный баланс и, если возможно, установить квоту самого ключа 4,50 USD в кабинете AIsa.
- Каждый ответ сохранять целиком в `raw/aisa/`, вместе с endpoint, payload без секрета, датой и фактической стоимостью.
- Для каждого вызова CLI использовать `--show-cost`: каталог помечает выбранные методы как `free`, но документация CLI отдельно предупреждает, что DataForSEO тарифицируется по фактическому расходу.
- Не повторять оплаченный запрос автоматически.

## Исходный план и фактическое решение

1. `keyword_suggestions/live` проверен для Москвы и России. Оба ответа вернули ошибку неподдерживаемого региона, стоимость 0 USD.
2. `google_ads/search_volume/live`, Google SERP и DataForSEO Search Intent не вызываются: DataForSEO официально не поддерживает Россию и Беларусь.
3. Вместо неподходящего источника выполнены три AIsa/Tavily Search по направлениям сайта: 30 результатов, 0,048 USD.
4. Выполнен один AIsa/Tavily Extract для восьми близких страниц конкурентов: 8 успешно, 0 ошибок, 0,016 USD.
5. Дополнительные вызовы остановлены: текущих данных достаточно для решения по структуре, а расходование остатка не является целью.

## Что сознательно не вызывается

- Платный LLM для кластеризации: кластеризацию можно выполнить локально по правилам `dinar-seo-system`.
- Полный backlink-аудит, Similarweb, Ahrefs и Semrush: не входят в первый бюджет 4,50 USD.
- Массовый crawl через AIsa: локальный код и публичные страницы уже доступны для проверки.
- Любые write-, posting-, account- или advertising-endpoints.
- DataForSEO для другой страны в качестве подмены московских данных.

## Критерий остановки

Пакет остановлен на 0,064 USD из-за достаточности данных и неподдерживаемого DataForSEO региона. Общий защитный предел 4,25 USD не достигнут. Не считать неиспользованный бюджет обязанностью потратить его полностью.
